# Serpulo ภาษาไทย — ชุด schematic 1.0

จัดทำ 13 ตุลาคม 2569 สำหรับ Mindustry บน iPad รุ่น 8.160.5 (Build 160.5)
แพ็กนี้มี 44 แบบ ใช้บล็อกเดิมเท่านั้น ไม่มี Java, JavaScript, processor หรือทรัพยากรใหม่
เป็นชุดโมดูลพื้นฐานถึงขั้นสูง ไม่ใช่ฐานสำเร็จรูปที่วางครั้งเดียวจบ ทุกแบบยังต้องต่อวัตถุดิบ ไฟ และวางบนพื้นที่ที่เหมาะสม

## นำเข้าจาก GitHub บน iPad
1. เปิด Mindustry > Mods (ม็อด) > Import from GitHub (นำเข้าจาก GitHub)
2. ใส่ชื่อรีโพซิทอรี `0tyght/mindustry-serpulo-th` แล้วกดยืนยัน
3. รอดาวน์โหลด เปิดใช้แพ็ก และรีสตาร์ตเกมตามที่เกมแจ้ง
4. เปิดรายการ Schematics หรือปุ่มแบบก่อสร้างระหว่างเล่น ค้นหา F02, L01 หรือคำไทย เช่น ซิลิคอน
5. แบบมีชื่อและคำอธิบายไทย พร้อมหมวดและจุดต่อ ถ้าตั้งภาษาเกมอื่น คำอธิบายของชุดนี้ยังเป็นไทย

หากดาวน์โหลดผ่านเมนู GitHub ไม่สำเร็จ ให้เปิดหน้ารีโพซิทอรี กด Code > Download ZIP แล้วเก็บไว้ในแอป Files จากนั้นเปิดเกม > Mods > Import Mod และเลือก ZIP โดยไม่แตกไฟล์

[ดูรายการทั้ง 44 แบบและจุดต่อ](SCHEMATICS-TH.md)

## นำเข้าเฉพาะแบบ โดยไม่ติดตั้งแพ็กม็อด
เปิดโฟลเดอร์ [schematics](schematics) เลือกไฟล์ `.msch` ที่ต้องการ แล้วใช้ปุ่มดาวน์โหลดของ GitHub เก็บไว้ในแอป Files จากนั้นเลือกไฟล์จากเมนูนำเข้า schematic ของเกม
แต่ละรายการใน [คู่มือแบบก่อสร้าง](SCHEMATICS-TH.md) มีลิงก์ไปยังไฟล์ของแบบนั้น
อย่านำเข้าแพ็กม็อดและแบบแยกชุดเดียวกันพร้อมกัน เพราะจะมีรายการซ้ำ

## เริ่มใช้ตามลำดับ
- ต้นเกม: M01 ขุดแร่ → F01 กราไฟต์ → P01 ไฟ → F02 ซิลิคอน → F03 เมตากลาส → D01/D02 ป้องกัน
- ขยายฐาน: P02 ไอน้ำ → F20 ซิลิคอน 4 ช่อง → U01 Mono → U04 Poly → P05 แบตเตอรี่
- กลาง/ปลายเกม: M03/M04, F04–F19 และอาวุธ D03–D05 เลือกตามทรัพยากรและเทคโนโลยีที่ปลดล็อก
- ไม่ใช่ทุกแบบเป็นแบบต้นเกม สายพานไทเทเนียมและท่อ Pulse ในแบบขั้นสูงต้องวิจัยก่อน
- ภาพคู่มือเป็นผังบล็อกและลูกศร ไม่ใช่ภาพเรนเดอร์ในเกม พิกัดนับจากซ้ายล่างเริ่มที่ 0 และใช้ก่อนหมุนแบบ
- สูตรโรงงานในคำอธิบายเป็นสูตรต่อเครื่อง ไม่ใช่การรับประกันผลผลิตจริง พื้น ไฟ น้ำ และความเร็วสายพานมีผล

## ระบบส่งทรัพยากรใหม่ของ v8
ต้นทาง: โรงงาน/เหมือง → L01 หรือ L02 + น้ำมัน + ไฟฟ้า → เลือกเซกเตอร์ปลายทาง
ปลายทาง: W01/W02 หรือแหล่งน้ำอื่น → L03/L04 → สายพาน → Core/คลัง

L01 ใช้ Advanced Launch Pad ขนาด 4×4 ไม่ใช่ Launch Pad เก่า 3×3
1 แท่นส่ง: 100 ชิ้นทุก 30 วินาที หรือ 200 ชิ้น/นาที น้ำมัน 9/วินาที และไฟฟ้า 480/วินาทีขณะชาร์จ
L02 รวม 6 แท่น: สูงสุด 1200 ชิ้น/นาที ต้องมีน้ำมัน 54/วินาที ไฟฟ้า 2880/วินาที และการผลิตวัตถุดิบพอ
ป้อนของชนิดเดียวต่อแท่น อย่าส่งสินค้าหลายชนิดปนเข้าทีละแท่น

Landing Pad รับ 100 ชิ้นต่อเที่ยว ใช้น้ำ 1500 หน่วยต่อเที่ยว ไม่ได้แค่มีท่อน้ำเล็กน้อยแล้วทำงานเต็มกำลัง
- รับ 200 ชิ้น/นาที: ต้องมีน้ำเฉลี่ย 50/วินาที
- รับ 1200 ชิ้น/นาที: ต้องมีน้ำเฉลี่ย 300/วินาที และระบายของ 20 ชิ้น/วินาที
W01 ปั๊มโรตารี 2 ตัวได้สูงสุดรวม 96 น้ำ/วินาทีเมื่อพื้นที่ปั๊มทั้งหมดอยู่บนน้ำ เหมาะกับการเริ่มรับจากแท่นส่ง 1 ตัว
W02 ปั๊มอิมพัลส์ 3 ตัวได้สูงสุดรวม 356.4 น้ำ/วินาทีเมื่อพื้นที่ปั๊มทั้งหมดอยู่บนน้ำ ต่อท่อหลายทางและตรวจถังแท่นรับจริง
ถังน้ำเป็นบัฟเฟอร์ ไม่ได้สร้างน้ำ และเครื่องขุดน้ำใต้ดินตัวเดียวไม่พอสำหรับฐานรับอัตราสูง
L03 ให้เลือกสินค้าที่จะรับเอง ส่วน L04 เลือกซิลิคอนไว้แล้ว มีทางออกสายพาน 3 สาย อย่ารวมเหลือไทเทเนียมสายเดียวถ้าส่งเกิน 11 ชิ้น/วินาที

## โฮสต์และการเปลี่ยนเส้นทาง
ระบบข้ามเซกเตอร์นี้ใช้กับแคมเปญของโฮสต์ ไม่ใช่ส่งทรัพยากรข้ามเซิร์ฟเวอร์หรือข้ามเซฟของเพื่อน
ให้โฮสต์เลือกสินค้าบนแท่นรับ แล้วกดปุ่มลูกศรเปลี่ยนเส้นทางส่ง เมื่อมีเซกเตอร์ต้นทางส่งสินค้าชนิดนั้นอยู่
ปลายทางเก็บเป็นค่าร่วมของทั้งเซกเตอร์ต้นทาง การเปลี่ยนเส้นทางจึงกระทบสินค้าทั้งหมดที่เซกเตอร์นั้นส่ง ไม่ใช่แค่ชนิดที่เลือก
หากต้องการส่งคนละปลายทางพร้อมกัน ควรแยกเซกเตอร์ต้นทางตามกลุ่มสินค้า
ไม่จำเป็นต้องรวมทุกอย่างผ่านฐานกลางแบบเก่า: ส่งจากฐานผลิตไปฐานที่กำลังเล่นโดยตรงได้
ถ้าเซฟเปิดโหมด legacy launch pads แบบ L01–L04 นี้จะไม่ตรงกับกติกา ต้องใช้ระบบใหม่ของแคมเปญ
ต้องปลดล็อกบล็อกและมีวัตถุดิบจริงก่อนสร้าง แพ็กไม่ปลดล็อกเทคโนโลยีและไม่เพิ่มทรัพยากร

## เล่นกับเพื่อน
ทุกแบบใช้บล็อกปกติของเกม แพ็กตั้ง hidden:true (แพ็กฝั่งผู้เล่นตามระบบ v8) และไม่มี content ใหม่ เพื่อนไม่จำเป็นต้องลงแพ็กเพื่อเห็นสิ่งก่อสร้างที่คุณวาง
เพื่อนต้องนำเข้าแบบเองเฉพาะเมื่อต้องการมีแบบในรายการของเขา
ทุกคนต้องใช้เวอร์ชันเกมที่เซิร์ฟเวอร์/โฮสต์รองรับ และกติกาแผนที่ยังอาจห้ามบางบล็อก
การทดสอบนี้ไม่ใช่การยืนยันการเชื่อมต่อ iPad กับเซิร์ฟเวอร์จริง

## การทดสอบและขอบเขต
ตรวจด้วยไฟล์ server-release.jar ทางการ Build 160.5:
- ทุกไฟล์อ่านกลับได้ ชื่อไทยคงอยู่ บล็อกไม่ซ้อน และลิงก์ไฟฟ้ามีระยะที่เกมยอมรับ
- ทดลองนำเข้า ZIP ผ่าน Mods.importMod แล้วพบครบ 44 แบบ และรายการม็อดที่บังคับให้เพื่อนติดตั้งว่างเปล่า
- จำลองโรงงาน F01–F17 และช่องแรกของ F20 โดยป้อนของผ่านสายพาน/ท่อภายนอก พร้อมไฟเต็ม
- จำลอง L01 และ L02: ภายใน 180 วินาที ทุกแท่นส่งได้ 5 เที่ยวหลังเริ่มป้อน
- จำลอง L03/L04 ในสภาพแวดล้อมทดสอบแบบ infiniteResources เพื่อยืนยันน้ำและทางออก ไม่ใช่การทดสอบการส่งข้ามเซกเตอร์ของแคมเปญ
- เครื่องขุด ปั๊มที่ต้องอาศัยพื้น ปืน และโรงงานยูนิต ตรวจโครงสร้างและการตั้งค่า แต่ไม่ได้จำลองการต่อสู้หรือทุกสภาพภูมิประเทศ
- ยังไม่ได้ทดสอบบน iPad จริงหรือห้องหลายผู้เล่นจริง

ตรวจชุด holmes-g/schematics แล้ว แต่หลายแบบใช้ logic และเงื่อนไขเฉพาะ จึงสร้างผังชุดนี้ใหม่เพื่อให้จุดต่อและคำอธิบายสม่ำเสมอ
ไม่ได้คัดลอกผังของชุดนั้นเข้ามา และไม่ต้องติดตั้ง Schematic Browser เพิ่ม
