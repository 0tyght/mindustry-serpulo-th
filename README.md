## เริ่มใช้

- ค้นคำไทยหรือรหัส เช่น **ซิลิคอน**, **PROD-059**, **UNIT-MONO-T2**, **CARGO-OIL-START** ในรายการ Schematics
- ป้าย **ทดสอบระบบ** หมายถึงผ่านการจำลองการผลิต/ขนส่งด้วยจุดต่อภายนอกที่ระบุ ป้าย **ตรวจผัง** หมายถึงตรวจบล็อก การวางและการตั้งค่าแล้ว แต่ยังไม่วัดการทำงานครบระบบ
- ป้าย **ทดสอบการป้อน** ใช้กับแนวป้องกันที่ตรวจว่าน้ำ/กระสุนและไฟเข้าถึงป้อมกับเครื่องซ่อม แต่ยังไม่ได้วัดการยิงหรือการรับเวฟ คำอธิบายแต่ละแบบระบุป้อมที่ยิงพื้นดิน/อากาศได้
- เปิดภาพของแบบที่เลือก ดูวัตถุดิบเข้า ผลผลิตออก ไฟฟ้า และเงื่อนไขพื้นก่อนวาง หมายเลขสีเขียวในภาพคือจุดป้อนของที่ใช้ทดสอบ พิกัดเริ่ม 0 จากซ้ายล่างก่อนหมุน
- แบบที่ใช้ Core ต้องแนบกับ Core ตามคู่มือ แบบที่ใช้แร่/น้ำต้องวางบนพื้นตรงเงื่อนไข แบบยูนิตต้องมีโควตาของทีมและเว้นทางออก
- โรงงานอัตราสูงต้องมีทางป้อนรวมที่เร็วพอ สายพานเส้นเดียวอาจจ่ายวัตถุดิบไม่ทัน แม้จำนวนเครื่องในผังมาก

## ระบบส่ง–รับ v8

ต้นทาง: **CARGO-OIL-START** ผลิตน้ำมันจากสปอร์ให้แท่นส่งหนึ่งตัว รับน้ำและไฟภายนอก ส่วน **CARGO-BELT-…** ใช้ต่อจากสายผลิต และ **CARGO-CORE-…** ใช้กับคลังแนบ Core

ปลายทาง: **RECEIVE-START-…** ขุดน้ำเองด้วย 8 Water Extractor เหมาะรับจากแท่นส่งหนึ่งตัวที่ 200 ชิ้น/นาที เมื่อพื้นมีประสิทธิภาพ 100% ส่วน **RECEIVE-FAST-…** รับน้ำภายนอกสำหรับอัตราสูง ผลทดสอบประมาณ 1,100 ชิ้น/นาทีเมื่อฐานอื่นส่ง 1,200 ชิ้น/นาที

มีแบบเลือกทรัพยากรไว้แล้วครบ 16 ชนิด ได้แก่ทองแดง ตะกั่ว ถ่านหิน ทราย เศษวัสดุ กราไฟต์ ซิลิคอน เมตากลาส ไทเทเนียม ทอเรียม พลาสตาเนียม ผ้าเฟส เซิร์จอัลลอย สปอร์ ไพราไทต์ และสารระเบิด

แท่นส่งใช้ Advanced Launch Pad ขนาด 4×4 ของระบบใหม่ ต่อแท่นใช้น้ำมัน 9/วินาทีและไฟ 480/วินาทีขณะชาร์จ แท่นรับใช้ 1,500 น้ำต่อเที่ยว 100 สินค้า ให้โฮสต์ตั้งปลายทางและเปลี่ยนเส้นทางส่งในแคมเปญ การเปลี่ยนมีผลทั้งเซกเตอร์ต้นทาง
