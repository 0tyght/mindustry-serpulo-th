ผลผลิต: เซิร์จอัลลอย  
จุดต่อเมื่อยังไม่หมุน: พิกัดเริ่ม 0 จากซ้ายล่าง  
ทองแดง เข้า @ 1,0  
ซิลิคอน เข้า @ 2,0

ไฟฟ้า @ 0,6
