# ซิลิคอน 6 เครื่อง ผังอัดแน่น ช่องป้อนเร็ว

**PROD-059** · 03 โรงงาน · 8×7 ช่อง · **ทดสอบระบบ**

![แปลน ซิลิคอน 6 เครื่อง ผังอัดแน่น ช่องป้อนเร็ว](../previews/PROD-059.png)

เหมาะกับ: ป้อนจากสายพาน  
รับ: ถ่านหิน, ทราย  
ผลผลิต: ซิลิคอน  
ช่องป้อนถ่านหินใช้สายพานไทเทเนียม; ต่อถ่านหินและทรายแยกกันตามจุดต่อ ตรวจอัตราจริงก่อนต่อขยาย  
จุดต่อเมื่อยังไม่หมุน: พิกัดเริ่ม 0 จากซ้ายล่าง  
ทราย เข้า @ 5,0  
ถ่านหิน เข้า @ 5,6  
ซิลิคอน ออก @ 0,2  
ไฟฟ้า @ 4,0  
ต่อผลผลิตเข้าคลังหรือโรงงานถัดไป เพื่อไม่ให้เครื่องหยุดเพราะทางออกเต็ม  
ผู้สร้างต้นฉบับ: susernaeme / Design-It (MIT)  
ปรับภาษาไทยและช่องต่อสำหรับชุดนี้  
ตรวจโครงสร้างและการตั้งค่า; อัตราผลิตต้องดูผลทดสอบจริงของแต่ละแบบ  
  
ผลทดสอบ Build 160.7: silicon 7.50/วินาที เมื่อป้อนวัตถุดิบที่จุดต่อและมีไฟครบ
