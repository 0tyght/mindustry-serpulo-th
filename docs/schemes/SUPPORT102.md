# ตัวควบคุมสะพาน — กันสินค้าอุดตัน

**SUPPORT102** · 09 สนับสนุนและ Logic · 1×1 ช่อง · **ตรวจผัง**

![แปลน ตัวควบคุมสะพาน — กันสินค้าอุดตัน](../previews/SUPPORT102.png)

จัดลำดับสะพานรับและส่งด้วย mlog  
วาง processor แล้ว link สะพานทางออกก่อน จากนั้น link สะพานทางเข้า; ใช้กับสะพานของทีมตนเองตามข้อความผู้สร้าง ไม่ต้องมียูนิตส่งของ  
มี mlog เดิมฝังในแบบ: ห้ามลบ processor หากยังใช้ระบบอัตโนมัติ; ดูวิธีตั้งค่าของผู้สร้างในคู่มือฉบับเต็ม
