# ตัวควบคุมทอเรียม — ปิดเมื่อไครโอขาด

![แปลน ตัวควบคุมทอเรียม — ปิดเมื่อไครโอขาด](../previews/SUPPORT103.png)

ควบคุมความเย็นและประหยัดเชื้อเพลิงของ reactor  
link processor ไป Thorium Reactor ทุกตัวในระยะ; ตรวจไฟ/ไครโอก่อนโหลดเชื้อเพลิง; logic เดิมปิดเมื่อไครโอต่ำและประหยัดเมื่อแบตเตอรี่เต็ม  
มี mlog เดิมฝังในแบบ: ห้ามลบ processor หากยังใช้ระบบอัตโนมัติ; ดูวิธีตั้งค่าของผู้สร้างในคู่มือฉบับเต็ม
