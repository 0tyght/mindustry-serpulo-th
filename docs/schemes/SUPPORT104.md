# ตัวควบคุมโรงไฟฟ้า — UniPlant

**SUPPORT104** · 09 สนับสนุนและ Logic · 1×1 ช่อง · **ตรวจผัง**

![แปลน ตัวควบคุมโรงไฟฟ้า — UniPlant](../previews/SUPPORT104.png)

เริ่มและควบคุมเครื่องกำเนิด Serpulo หลายชนิด  
link ไปเครื่องกำเนิด/reactor และ overdrive ในระยะ จ่ายน้ำ/เชื้อเพลิง/ไฟเริ่มต้นตามแต่ละชนิด; switch ที่เปิดช่วย override การประหยัด อ่านเงื่อนไขตัวควบคุมก่อนใช้  
มี mlog เดิมฝังในแบบ: ห้ามลบ processor หากยังใช้ระบบอัตโนมัติ; ดูวิธีตั้งค่าของผู้สร้างในคู่มือฉบับเต็ม  
  
แหล่ง: Design-It / cirrocco  
ต้นฉบับ: CCER UniPlant 6.01  
MIT; แปลชื่อและคู่มือโดยชุด Serpulo ไทย 2.0  
อ่าน/โครงสร้างผ่านแล้ว ผลทดสอบการทำงานเฉพาะรหัสอยู่ในคู่มือ อัตราจริงขึ้นกับแผนที่และวัตถุดิบ
