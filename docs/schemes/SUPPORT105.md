# PowerFlow — แยกไฟเริ่มระบบจากโหลดฐาน

**SUPPORT105** · 09 สนับสนุนและ Logic · 4×3 ช่อง · **ตรวจผัง**

![แปลน PowerFlow — แยกไฟเริ่มระบบจากโหลดฐาน](../previews/SUPPORT105.png)

ควบคุมไฟเพื่อให้โรงไฟฟ้าติดก่อนจ่ายฐาน  
ต่อด้าน processor/bottom เข้าฝั่งโรงไฟฟ้า ต่อด้านข้อความ/top ไปฝั่งโรงงานหรือป้อมปืน อ่านภาพขั้ว diode ก่อนหมุน; ผังนี้ไม่ผลิตไฟเอง  
มี mlog เดิมฝังในแบบ: ห้ามลบ processor หากยังใช้ระบบอัตโนมัติ; ดูวิธีตั้งค่าของผู้สร้างในคู่มือฉบับเต็ม  
  
แหล่ง: Design-It / cirrocco
